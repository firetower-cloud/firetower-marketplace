# Skills

Entries that are instructions rather than a connection. Nothing here yet, and
that is worth saying out loud: everything this marketplace publishes today is
an MCP server, which means it saves somebody a copy-paste and little else.

A server's tool names say *what* it can do. They do not say *how* — which
project board the team actually uses, what a good triage note looks like, how
to map a Figma frame onto the design system that already exists. That is what
belongs here.

## Which directory

| | |
| --- | --- |
| `mcp/` | the entry's point is a server to call |
| `skills/` | the entry's point is instructions to read |

An entry that carries both goes where its point is. `mcp/github` ships one
skill and still lives under `mcp/`, because somebody adding it wants GitHub's
tools and gets the skill with them.

The layout of an entry is identical in both directories — a manifest, and
whatever it carries. The split is for people reading the repository, not for
anything that parses it.
